# 24 — Exercises

## What Exercises Covers

Six **cross-cutting practice problems**, each deliberately combining two or three modules already built in this repository, rather than drilling one topic in isolation. Per this repository's top-level README, this collection is distinct from the per-module exercises already found inside individual modules (e.g., [09-Object-Oriented-Programming/Exercises](../09-Object-Oriented-Programming/Exercises/), [10-Functional-Programming/Exercises](../10-Functional-Programming/Exercises/)) — those drill one module's concepts directly; these problems specifically require combining knowledge across modules, the way a real feature usually does.

## How to Use This Module

Attempt each problem yourself, referencing the linked modules if you need a refresher, **before** looking at the matching solution in [25-Solutions](../25-Solutions/README.md) — solutions are kept in a separate folder specifically so you aren't tempted to peek early.
