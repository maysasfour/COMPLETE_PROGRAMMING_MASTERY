## How to Work Through These

1. Read the lesson(s) listed for the exercise first.
2. Write your solution in a scratch `.py` file — don't peek at `Solutions/` until you've attempted it.
3. Run your solution and check it against the described expected behavior in each exercise.
4. Compare with the matching file in `Solutions/` for the reference approach and explanation — there's often more than one reasonable design; the solution explains the trade-offs of the one chosen.
