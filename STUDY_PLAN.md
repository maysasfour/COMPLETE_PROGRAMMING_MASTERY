## 30-Day Plan

Goal: solid fundamentals and one language, ready to build small programs.

| Days | Focus |
|------|-------|
| 1–5 | [00-Programming-Fundamentals](00-Programming-Fundamentals/) |
| 6–18 | [01-Languages/Python](01-Languages/Python/) full course |
| 19–24 | [09-Object-Oriented-Programming](09-Object-Oriented-Programming/) |
| 25–30 | [08-Data-Structures-and-Algorithms](08-Data-Structures-and-Algorithms/) intro (arrays, linked lists, complexity, sorting) + Beginner project |

## 60-Day Plan

Everything in the 30-day plan, plus:

| Days | Focus |
|------|-------|
| 31–40 | Rest of [08-Data-Structures-and-Algorithms](08-Data-Structures-and-Algorithms/) (trees, graphs, DP) |
| 41–45 | [02-Markup-and-Styling](02-Markup-and-Styling/) |
| 46–55 | [03-Frontend-Development](03-Frontend-Development/) basics + [04-Backend-Development](04-Backend-Development/) basics |
| 56–60 | Build one Beginner + start one Intermediate project from [22-Projects](22-Projects/) |

## 90-Day Plan

Everything in the 60-day plan, plus:

| Days | Focus |
|------|-------|
| 61–70 | [07-Databases](07-Databases/) — SQL fundamentals, one relational DB, one ORM |
| 71–78 | [14-APIs-and-Integrations](14-APIs-and-Integrations/) — REST, auth, JWT |
| 79–85 | [11-Design-Principles](11-Design-Principles/) + [12-Design-Patterns](12-Design-Patterns/) core patterns |
| 86–90 | [15-Testing-and-Debugging](15-Testing-and-Debugging/) basics + finish Intermediate project with tests |

By day 90 you should have: one strong language, working DSA fundamentals, a full-stack CRUD project with a database, tests, and version control — enough for junior-level interviews.

## 6-Month Plan

Months 1–3: the 90-day plan above.

| Month | Focus |
|-------|-------|
| 4 | [13-Software-Architecture](13-Software-Architecture/) + [16-Security](16-Security/) + [17-Git-and-GitHub](17-Git-and-GitHub/) advanced (rebase, Git Flow) |
| 5 | [18-DevOps-and-Cloud](18-DevOps-and-Cloud/) — Docker, CI/CD, one cloud deploy. Start an Advanced project. |
| 6 | [05-Mobile-Development](05-Mobile-Development/) or [06-Desktop-Development](06-Desktop-Development/) (pick one). Begin [21-Interview-Preparation](21-Interview-Preparation/). |

## 1-Year Plan

Months 1–6: the 6-month plan above.

| Months | Focus |
|--------|-------|
| 7–8 | Second programming language, comparing idioms against your first (use [TECHNOLOGY_COMPARISON.md](TECHNOLOGY_COMPARISON.md)) |
| 9 | Second frontend or backend framework |
| 10 | Complete an Advanced project end-to-end (microservices or event-driven, from [22-Projects](22-Projects/)) with full test coverage and CI/CD |
| 11 | Deep [21-Interview-Preparation](21-Interview-Preparation/) — mock interviews, system design, behavioral prep |
| 12 | Polish portfolio, contribute to open source, apply, iterate on weak areas identified in [SKILL_ASSESSMENT.md](SKILL_ASSESSMENT.md) |
