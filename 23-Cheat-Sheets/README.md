# 23 — Cheat Sheets

[Back to repository root](../README.md)

## What Cheat Sheets Covers

One-page, fast-lookup references for the concept modules built across this repository, plus an index into the per-language cheat sheets that already exist inside each language's own course folder. Each cheat sheet is a **syntax and quick-recall reference**, not a teaching document — per this repository's own [top-level README](../README.md#how-to-use-this-repository), cheat sheets are meant to be used "once you already understand the concepts," pointing back to the full, verified lesson for anything that needs deeper explanation.

**Note on languages:** every one of this repository's 12 language courses already has its own `CHEAT-SHEET.md` inside its course folder (built alongside that course's 22 lessons, not as part of this module). Rather than duplicate that content here — which this repository's conventions explicitly avoid — this module's table below links directly to those existing files.

## Why This Is Reference Content, Not New Lessons

Every code snippet in every cheat sheet reflects syntax and patterns already taught and verified in this repository's full courses/modules — nothing here introduces a new concept without a link back to where it was actually built and run. Where a cheat sheet references a specific real, verified finding (a measured race condition, a real SQL injection exploit, a real network partition), that reference points to the exact lesson where it was compiled, executed, and its output captured — consistent with this repository's discipline of never asserting something was "verified" without it actually having been. See the root [README.md](../README.md#how-to-use-this-repository) for where cheat sheets fit into this repository's suggested workflow.

## How to Use This Module

Skim the relevant cheat sheet for fast syntax recall during actual work, or as a pre-interview refresher (see [21-Interview-Preparation](../21-Interview-Preparation/README.md), which serves a complementary but distinct purpose — Q&A-style revision rather than syntax lookup). Follow any link back to the full lesson whenever a snippet's context or reasoning isn't already clear from memory.
