# 12 — Dynamic Programming

[Back to module overview](../README.md)

**Planned — not yet implemented.**

This lesson will cover recognizing problems with overlapping subproblems and optimal substructure, the two implementation styles (top-down memoization vs. bottom-up tabulation), and a progression of classic examples (Fibonacci revisited, coin change, longest common subsequence, 0/1 knapsack). It builds directly on `08-Recursion` in this same module — the naive-vs-memoized Fibonacci example there is deliberately the first half of this lesson, previewed early because the contrast is one of the clearest ways to motivate why dynamic programming exists.
