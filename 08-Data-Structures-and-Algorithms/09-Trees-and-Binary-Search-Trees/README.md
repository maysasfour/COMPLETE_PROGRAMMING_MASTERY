# 09 — Trees and Binary Search Trees

[Back to module overview](../README.md)

**Planned — not yet implemented.**

This lesson will cover hierarchical (non-linear) data structures: general tree terminology (root, leaf, height, depth), binary trees, binary search trees (insert, search, delete, in-order/pre-order/post-order traversal), and an introduction to tree balancing (why an unbalanced BST degrades to O(n) and what self-balancing trees like AVL/red-black trees fix). It builds directly on the linked-list and recursion foundations from `03-Linked-Lists` and `08-Recursion` in this same module, since a tree is naturally implemented as linked nodes and most tree operations are naturally recursive.
