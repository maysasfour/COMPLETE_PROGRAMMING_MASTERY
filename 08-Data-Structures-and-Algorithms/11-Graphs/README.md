# 11 — Graphs

[Back to module overview](../README.md)

**Planned — not yet implemented.**

This lesson will cover graph representations (adjacency list vs. adjacency matrix), directed vs. undirected and weighted vs. unweighted graphs, and the core traversal/search algorithms: breadth-first search, depth-first search, and an introduction to shortest-path algorithms (Dijkstra's algorithm) and cycle detection. It builds on `04-Stacks-and-Queues` (BFS uses a queue, DFS uses a stack or recursion) and `09-Trees-and-Binary-Search-Trees` (a tree is a restricted special case of a graph).
