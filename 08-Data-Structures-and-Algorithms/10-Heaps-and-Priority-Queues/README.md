# 10 — Heaps and Priority Queues

[Back to module overview](../README.md)

**Planned — not yet implemented.**

This lesson will cover the heap data structure (min-heap and max-heap), how it's typically implemented as an array with implicit tree indexing, the sift-up/sift-down operations that keep it valid in O(log n), and how it's used to build a priority queue (including Python's built-in `heapq` module). It builds on `09-Trees-and-Binary-Search-Trees` (a heap is a specialized tree shape) and `06-Sorting-Algorithms` (heapsort is a natural follow-on once heaps are understood).
