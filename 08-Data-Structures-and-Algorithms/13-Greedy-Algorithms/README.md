# 13 — Greedy Algorithms

[Back to module overview](../README.md)

**Planned — not yet implemented.**

This lesson will cover the greedy strategy (making the locally optimal choice at each step and hoping/proving it leads to a globally optimal solution), how to recognize when greedy actually works versus when it produces a wrong answer that looks plausible, and classic examples (activity selection, fractional knapsack, coin change with canonical coin systems, Huffman coding). It builds on `12-Dynamic-Programming`, since the clearest way to teach greedy algorithms is by contrast with DP — greedy problems are the subset of DP-shaped problems where you don't actually need to explore all subproblems.
