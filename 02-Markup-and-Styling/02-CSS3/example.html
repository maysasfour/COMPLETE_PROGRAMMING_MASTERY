Flexbox, Grid, and Custom Properties Together

The navbar above is a Flexbox row (display: flex; justify-content: space-between). The cards below are a responsive Grid (repeat(auto-fit, minmax(200px, 1fr))) that reflows automatically as you resize the window — try it. Hover a card to see a transform-based lift, and toggle your OS/browser dark mode to see the colors repaint via prefers-color-scheme, with zero JavaScript.

Responsive Card Grid

Flexbox

One-dimensional layout along a row or column. Ideal for navbars and button groups.

Grid

Two-dimensional layout with explicit rows and columns. Ideal for whole-page layouts and galleries.

Custom Properties

Runtime CSS variables that make theming, including dark mode, trivial to implement.

Transitions

Animating transform/opacity keeps animations on the compositor thread.

Mobile-First

min-width media queries progressively enhance from a small-screen baseline.

Box Model

box-sizing: border-box makes declared width include padding and border.
