# Exercises - Control Flow

1. Write a `fizzbuzz(n)` function that prints "Fizz"/"Buzz"/"FizzBuzz"/the number for 1..n using a numeric `for` loop.
2. Write a loop using `repeat...until` that keeps "rolling a die" (`math.random(1,6)`) until it rolls a 6, printing each roll, and counts how many rolls it took.
3. Given `local words = {"lua", "is", "fun"}`, use `ipairs` to print each word with its 1-based index.
4. Since Lua has no `continue`, use `goto`/a label to print only the odd numbers from 1 to 10 in a single `for` loop (skip even numbers via the goto-continue pattern).
