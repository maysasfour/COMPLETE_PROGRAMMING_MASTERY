# Exercises - Tables

1. Given `local nums = {5, 2, 8, 1, 9}`, write a function `sum_table(t)` that sums a 1-based array table using `#`/numeric `for`.
2. Write `reverse_table(t)` that returns a NEW table with `t`'s elements in reverse order, without mutating `t`.
3. Given a table of `{name=..., score=...}` records, write `top_scorer(records)` that returns the record with the highest `score` (iterate with `ipairs`).
4. Build a simple frequency-count table from a list of words (e.g. count how many times each word appears) using a table as a dictionary, then print each word with its count via `pairs`.
