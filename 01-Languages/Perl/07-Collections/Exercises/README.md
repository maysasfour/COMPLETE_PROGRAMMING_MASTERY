# Exercises — Collections

1. Given `my @words = qw(pear apple kiwi banana fig);`, use `sort` with a custom comparator to sort them by LENGTH, shortest first (ties broken alphabetically).
2. Given `my %inventory = (apples => 5, bananas => 0, cherries => 12, dates => 0);`, use `grep` to find item names with a count of 0 (out of stock).
3. Given `my @nums = (1..10);`, use `map`+`grep` together to produce the squares of only the odd numbers.
