# Exercises — Control Flow

1. Write a script that loops `1..20` and prints `"Fizz"` for multiples of 3, `"Buzz"` for multiples of 5, `"FizzBuzz"` for both, and the number otherwise. Use postfix `if`/`unless` at least once.
2. Given `my @scores = (95, 82, 71, 40);`, classify each into a letter grade (A/B/C/F) using `if`/`elsif`, and print `"$score -> $grade"` for each.
3. Use `until` (not `while`) to count down from 5 to 1 and print each value.
