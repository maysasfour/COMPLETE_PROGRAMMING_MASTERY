# Exercises: Control Flow

1. Write a `switch -Regex` statement that classifies a string as "email", "phone number" (digits/dashes only), or "unknown".
2. Use a script-block `switch` case to print "fizz", "buzz", "fizzbuzz", or the number itself for 1..20 (FizzBuzz).
3. Write a `while` loop that sums numbers from a queue (array) until it exceeds 100, printing the running total each iteration.
4. Demonstrate, with real output, that a `switch` without `break` can match more than one case for the same input.
