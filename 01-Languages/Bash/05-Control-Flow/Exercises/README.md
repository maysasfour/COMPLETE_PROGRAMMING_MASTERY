# Exercises — Control Flow

1. Write a script `fizzbuzz.sh` that prints "Fizz" for multiples of 3, "Buzz" for multiples of 5, "FizzBuzz" for multiples of both, and the number otherwise, for 1 through 15.
2. Write a script `classify.sh` that reads a filename as `$1` and uses `case` to print "shell script" for `*.sh`, "text file" for `*.txt`, or "unknown type" otherwise.
