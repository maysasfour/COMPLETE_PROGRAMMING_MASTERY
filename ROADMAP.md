The recommended order to work through this repository. You don't have to follow it exactly — jump to what you need — but if you're starting from zero, follow this order top to bottom.

## Phase 1 — Foundations

1. [00-Programming-Fundamentals](00-Programming-Fundamentals/) — how programs run, variables, control flow, functions, memory, errors.
2. [20-Computer-Science-Fundamentals](20-Computer-Science-Fundamentals/) — binary, boolean logic, OS basics, networking basics (skim now, revisit later).
3. [19-Command-Line-and-Operating-Systems](19-Command-Line-and-Operating-Systems/) — comfortable in a terminal before anything else.
4. [17-Git-and-GitHub](17-Git-and-GitHub/) — version control from day one.

## Phase 2 — Core Language Mastery

5. Pick **one** language from [01-Languages](01-Languages/) and go deep — Python is the recommended first language in this repo (fully built out as the reference course).
6. [09-Object-Oriented-Programming](09-Object-Oriented-Programming/)
7. [10-Functional-Programming](10-Functional-Programming/)

## Phase 3 — Problem Solving

8. [08-Data-Structures-and-Algorithms](08-Data-Structures-and-Algorithms/) — complexity analysis first, then data structures, then algorithms. This is the highest-leverage module for interviews.

## Phase 4 — Web Fundamentals

9. [02-Markup-and-Styling](02-Markup-and-Styling/) — HTML, CSS, JSON, YAML.
10. Revisit JavaScript/TypeScript in [01-Languages](01-Languages/) if not chosen as your primary language.

12. [04-Backend-Development](04-Backend-Development/)

21. [05-Mobile-Development](05-Mobile-Development/) and/or [06-Desktop-Development](06-Desktop-Development/) depending on your goals.

## Phase 9 — Portfolio and Interviews
